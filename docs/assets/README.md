# Documentation Assets

Repository-hosted SVG assets used by the documentation:

| Asset | Purpose |
|---|---|
| `niyah-engine-banner.svg` | Project landing-page identity and system summary |
| `niyah-engine-architecture.svg` | End-to-end runtime architecture |
| `heldout-learning-curve.svg` | Diagnostic held-out loss/perplexity trajectory through step 1905 |
| `documentation-map.svg` | Documentation information architecture |
| `local-evidence-2026-09-24.svg` | Dated visual dashboard for observed local corpus, tokenizer-preparation, CSI CUDA, synthetic-data, and external-RAG evidence |

The SVGs are source-controlled text assets so documentation remains self-contained and does not depend on an external image host.

Charts and dashboards are descriptive of recorded evidence only. They are not benchmark-comparison graphics and do not elevate local work-in-progress observations into release claims.
